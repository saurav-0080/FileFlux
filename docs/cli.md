# CLI Documentation

## Available Commands

| Command      | Purpose                          |
|---|---|
| scan         | Scan a directory and show stats  |
| organize     | Organize files into folders      |
| duplicates   | Find duplicate files             |
| undo         | Undo the latest session          |
| history      | View organization statistics     |
| version      | Show application version         |
