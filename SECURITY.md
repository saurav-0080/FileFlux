# Security Policy

## Checklist

- ✔ No secrets committed
- ✔ Path traversal protected
- ✔ Protected directories (/, /bin, /usr, /etc, /System, /Library, project root)
- ✔ Symlinks rejected as source directories
- ✔ No silent file overwrites (conflict resolution via renaming)
- ✔ Configuration validation with fallback to defaults
- ✔ Safe exception handling
- ✔ SQLite error handling
- ✔ .env excluded from version control
