# Changelog

## v1.0.0 — 2026-08-13

### Added
- File scanner with recursive directory support
- Rule-based file organization engine
- SQLite operation history
- Undo system
- Duplicate detection with size-grouping + SHA-256
- Full Tkinter GUI
- CLI with 6 subcommands (scan, organize, duplicates, undo, history, version)
- JSON and CSV operation reports
- Progress tracking
- Docker support
- GitHub Actions CI pipeline (tests, lint, build, Docker validation)
